# مدل تهدید موتور Source Sync

## دارایی‌های حساس

- آخرین Snapshot تأییدشده منابع رسمی
- تصمیم‌های مدیر و Audit Log
- فهرست URLهای مجاز
- وضعیت منابع در CivilMind AI
- دسترسی Admin و توابع Internal Convex

## تهدیدها و کنترل‌ها

### SSRF

**تهدید:** مهاجم URL داخلی، IP خصوصی، Metadata Endpoint یا دامنه دیگری را به موتور تحمیل کند.

**کنترل:** URL از ورودی Client دریافت نمی‌شود. منبع از Registry داخلی خوانده می‌شود و Host، HTTPS، Port و Credential در هر درخواست و Redirect اعتبارسنجی می‌شوند.

### Redirect Escape

**تهدید:** منبع مجاز به دامنه مخرب Redirect شود.

**کنترل:** `redirect: manual` و اعتبارسنجی مجدد مقصد؛ حداکثر سه Redirect.

### پاسخ بسیار بزرگ

**تهدید:** مصرف حافظه یا زمان با Payload بزرگ.

**کنترل:** بررسی Content-Length، خواندن Stream با سقف دو مگابایت و قطع Reader پس از عبور از حد.

### محتوای فعال یا فایل اجرایی

**تهدید:** ورود فایل اجرایی، HTML فعال یا محتوای با MIME جعلی.

**کنترل:** Allowlist نوع محتوا، بررسی پسوند اجرایی، Signature PDF، Meta Refresh، Object/Embed، JavaScript URL و الگوهای اجرای پویا. موارد High و Critical قرنطینه می‌شوند.

### انتشار بدون تأیید

**تهدید:** Snapshot جدید مستقیماً جایگزین نسخه معتبر شود.

**کنترل:** فقط Baseline اولیه سالم خودکار ثبت می‌شود. تمام تغییرات بعدی Proposal می‌سازند و `lastSnapshotId` تا تصمیم Admin تغییر نمی‌کند.

### جعل نقش مدیر

**تهدید:** کاربر عادی با تغییر UI عملیات مدیریتی اجرا کند.

**کنترل:** تمام Query و Mutationهای مدیریت از `requireAdmin` در Backend استفاده می‌کنند. UI تنها لایه نمایشی است.

### تأیید محتوای قرنطینه‌شده

**تهدید:** مدیر به اشتباه Snapshot قرنطینه‌شده را Promote کند.

**کنترل:** Backend تأیید Proposal قرنطینه‌شده و Promotion Snapshot با وضعیت `quarantined` را رد می‌کند.

### Rollback مخرب

**تهدید:** بازگشت به Snapshot مشکوک یا متعلق به منبع دیگر.

**کنترل:** Rollback فقط برای Snapshot همان `sourceKey` و فقط با وضعیت `clean` مجاز است.

### اجرای هم‌زمان

**تهدید:** چند Sync هم‌زمان Proposal تکراری یا فشار روی منبع ایجاد کند.

**کنترل:** پیش از ساخت Run جدید، وضعیت‌های `queued` و `running` بررسی می‌شوند. Hash و Proposal بر اساس `sourceKey + contentHash` نیز Deduplicate می‌شوند.

## باقیمانده ریسک

- Regex جایگزین HTML Parser امنیتی کامل نیست؛ خروجی فقط متن نرمال‌شده است و هرگز به‌عنوان HTML اجرا نمی‌شود.
- تغییرات معنایی کوچک ممکن است با Diff ساده به‌طور کامل توضیح داده نشوند.
- دسترس‌نبودن سایت رسمی باعث Run ناقص می‌شود، اما Last-Known-Good را تغییر نمی‌دهد.
- پردازش عمیق PDF به Sprint آینده موکول شده است.
