# مرزهای امنیتی معماری چند ارائه‌دهنده AI

این سند معماری آینده را تعریف می‌کند؛ هیچ SDK، احراز هویت، billing یا فراخوانی
ارائه‌دهنده در این Sprint پیاده‌سازی نشده است.

## ارائه‌دهندگان آینده

- OpenAI API ارائه‌دهنده اصلی است.
- Gemini API فقط برای سهمیه رایگان محدود یا fallback کنترل‌شده در نظر گرفته
  می‌شود.
- Anthropic API برای مصرف پولی یا BYOK اختیاری آینده در نظر گرفته می‌شود.

ChatGPT Plus یک API backend نیست و Claude Pro نیز API backend نیست. اعتبارنامه
حساب‌های مصرف‌کننده نباید دریافت، ذخیره یا میان کاربران و سرورها به اشتراک
گذاشته شود.

## مرز کلید و مرورگر

کلید ارائه‌دهنده فقط در backend و secret store محیط اجرا باقی می‌ماند. هیچ کلید
ارائه‌دهنده به browser، bundle فرانت‌اند، log عمومی یا پاسخ API ارسال نمی‌شود و
هیچ کلیدی در Git commit نمی‌شود. کد frontend ذاتاً برای مرورگر عمومی است؛ بنابراین
هر چیزی که secret است باید پشت مرز backend بماند.

BYOK در آینده می‌تواند به‌صورت اختیاری اضافه شود، اما کلید کاربر نیز باید
رمزشده، server-side و بدون قابلیت بازخوانی از browser نگهداری شود.

## برنامه‌ها و مجوزها

برنامه‌های آینده شامل `free`، `premium` و `admin` هستند. کاربران premium فقط
سهمیه محدود و قابل اندازه‌گیری از بودجه API تأمین‌شده توسط سرور می‌گیرند.
ابزارهای admin هرگز به کاربران عادی expose نمی‌شوند. ابزارهای AI کاربر فقط از
allowlist صریح و حداقلی انتخاب می‌شوند؛ مدل حق فراخوانی ابزار داخلی دلخواه را
ندارد.

برای هر درخواست، quota، token accounting، سقف بودجه هر ارائه‌دهنده، circuit
breaker، timeout، محدودیت concurrency و audit log لازم است. fallback نباید سقف
بودجه یا سیاست داده ارائه‌دهنده مقصد را دور بزند.

## مرز retrieval و منابع رسمی

منابع retrieval کاربران عادی هرگز شامل source code، system prompt، deployment
secret، script، ابزار داخلی یا داده‌های admin نیست. جداسازی tenant و کنترل
مالکیت داده باید پیش از بازیابی اعمال شود.

AI می‌تواند candidate تغییر منبع رسمی، اختلاف metadata یا خلاصه‌ای برای reviewer
پیشنهاد کند، اما قادر به تأیید، انتشار یا تغییر وضعیت منبع نیست. تأیید منبع
همیشه از جریان مستقل و انسانی admin عبور می‌کند.

## خارج از دامنه این Sprint

نصب SDK ارائه‌دهندگان، احراز هویت، billing، BYOK، مدیریت پلن، endpoint چت،
فراخوانی مدل، ابزار admin و حسابداری مصرف عمداً پیاده‌سازی نشده‌اند.
