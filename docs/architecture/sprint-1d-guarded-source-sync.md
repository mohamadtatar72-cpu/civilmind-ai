# Sprint 1D — همگام‌سازی محافظت‌شده منابع رسمی

## هدف

این Sprint موتور پایش فقط‌خواندنی منابع رسمی CivilMind AI را فعال می‌کند. موتور هیچ محتوایی را مستقیماً منتشر نمی‌کند و تنها Snapshot، گزارش امنیتی و پیشنهاد تغییر می‌سازد.

## جریان اصلی

1. اجرای دستی مدیر یا Cron شش‌ساعته یک `sourceSyncRun` ایجاد می‌کند.
2. فقط منابع فعال ثبت‌شده در جدول `officialResources` خوانده می‌شوند.
3. URL پیش از هر درخواست و پس از هر Redirect دوباره اعتبارسنجی می‌شود.
4. پاسخ با محدودیت زمان، حجم و Content-Type دریافت می‌شود.
5. متن قابل‌مقایسه نرمال و SHA-256 محاسبه می‌شود.
6. اولین Snapshot سالم به‌عنوان Baseline و Last-Known-Good ذخیره می‌شود.
7. محتوای بدون تغییر فقط زمان آخرین بررسی را به‌روزرسانی می‌کند.
8. تغییر جدید Snapshot مستقل و `sourceChangeProposal` می‌سازد.
9. تغییر پرخطر قرنطینه می‌شود و امکان تأیید مستقیم ندارد.
10. مدیر می‌تواند Snapshot سالم را تأیید کند یا نسخه قبلی را نگه دارد.
11. Rollback فقط به Snapshot با وضعیت امنیتی `clean` مجاز است.

## جداول

### sourceSyncRuns

وضعیت اجرای کامل موتور، نوع Trigger، شمارنده نتایج و خلاصه خطاها را نگهداری می‌کند.

### sourceSyncItems

نتیجه هر منبع در یک Run را با وضعیت‌های Baseline، Unchanged، Proposal، Quarantined یا Failed ثبت می‌کند.

### sourceSnapshots

نسخه تغییرناپذیر محتوای نرمال‌شده، Hash، مشخصات HTTP، نتیجه اسکن و رابطه با نسخه قبلی را نگهداری می‌کند.

### sourceChangeProposals

پیشنهاد تصمیم مدیر را به Snapshot، Run، Diff Summary و یافته‌های امنیتی متصل می‌کند.

## مرزهای امنیتی

- دامنه مجاز فقط `inbr.ir` و `www.inbr.ir` است.
- فقط HTTPS و پورت استاندارد 443 پذیرفته می‌شود.
- Credential داخل URL ممنوع است.
- Redirect به دامنه خارج از Allowlist متوقف می‌شود.
- حداکثر سه Redirect پذیرفته می‌شود.
- Timeout هر درخواست ۱۲ ثانیه است.
- حداکثر پاسخ ۲ مگابایت است.
- متن ذخیره‌شده حداکثر ۲۰۰ هزار نویسه است.
- فایل اجرایی و Content-Type ناشناخته قرنطینه می‌شوند.
- هیچ تابع Client اجازه تعیین URL دلخواه ندارد.
- اجرای دستی، مشاهده Queue، تأیید، رد و Rollback فقط برای Admin است.
- Scheduler فقط تابع Internal را اجرا می‌کند.

## Last-Known-Good

فیلدهای `lastContentHash` و `lastSnapshotId` در `officialResources` همیشه به آخرین نسخه تأییدشده اشاره می‌کنند. Snapshot جدید پیش از تأیید این دو فیلد را تغییر نمی‌دهد.

## رفتار خطا

خطای یک منبع کل Run را متوقف نمی‌کند. نتیجه آن منبع `failed` ثبت می‌شود و Run با وضعیت `partial` پایان می‌یابد. اگر همه منابع شکست بخورند، Run با وضعیت `failed` بسته می‌شود.

## موارد خارج از محدوده

- انتشار خودکار محتوای منبع
- دانلود و پردازش عمیق PDF
- استخراج هوشمند تغییرات با مدل زبانی
- ارسال اعلان خارجی
- اتصال به Billing یا سرویس پولی
