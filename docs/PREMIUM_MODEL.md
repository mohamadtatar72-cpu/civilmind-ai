# Access and Premium Model

| Capability | Guest | Registered | Premium |
|---|---:|---:|---:|
| Official documents, questions and keys | Yes | Yes | Yes |
| Discipline/qualification filtering and search | Yes | Yes | Yes |
| Dashboard, history, bookmarks, practice | Preview | Yes | Yes |
| AI requests | Demo | Limited | Unlimited |
| Copilot, voice, tutor, PDF chat, prediction | Preview | Locked/limited | Yes |

Premium features must remain visible with a preview and upgrade dialog; do not hide product value.
