## Single-worker continuation law

1. Only the Codespaces implementation worker may edit source files, commit, push or deploy Preview.
2. AI Project Manager commands and ChatGPT Work reviews arrive through GitHub Issue #21.
3. Reviews never modify code.
4. If no new command or review arrives within the configured timeout, the worker selects exactly one bounded safe sprint from this matrix.
5. Every sprint must include real implementation, frontend/backend connection where applicable, tests, typecheck, lint, build, Changelog, Commit, Push and Preview when available.
6. A missing external engine or provider blocks only its dependent work; independent safe work continues.
7. No evidence means no completion.
