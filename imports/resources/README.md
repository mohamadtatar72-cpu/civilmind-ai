# CivilMind AI Resource Imports

## External resources

`external-resources.csv` contains official and trusted external sources.

Third-party copyrighted content must not be copied into the repository.
CivilMind AI only displays:

- title;
- category;
- source name;
- description;
- tags;
- direct original-source link.

## Local files

Only authorized files may be placed under:

`imports/resources/files/`

Allowed examples:

- official public PDFs;
- public-domain files;
- project-owned files;
- freely redistributable files;
- files with explicit redistribution permission.
